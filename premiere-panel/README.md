# Premiere-Panel (Skelett, ungetestet)

Meilenstein 0 des Projektheftes: Dieses UXP-Panel konnte hier nicht in Premiere Pro getestet werden.
Was funktioniert (nach Installation): Schnittpaket vom lokalen Tool oder aus einer Datei laden, Zusammenfassung und Warnungen zeigen.
Offen (Go/No-Go-Vorab-Test): Sequenz/Spuren anlegen, Clips setzen, MOGRT-Credits, Effekt-Rezepte, Konturfarbe, „Auf HQ umschalten“.

Installieren zum Testen: Adobe UXP Developer Tool → „Add Plugin“ → `manifest.json` wählen → „Load“.
Bis das Panel fertig ist: FCP-XML aus dem Tool (Rohschnitt-Ansicht → „Premiere-XML“) in Premiere importieren.
